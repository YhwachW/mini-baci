# Mini BACI

Simulador de programas C-- concurrentes, al estilo jBACI, para Android.
Soporta `cobegin`, `semaphore`, `binarysem`, `wait`, `signal`, `atomic`, funciones, arreglos y `cout`.

Abre la página en Chrome para Android y toca **Instalar app** (o menú ⋮ → *Instalar aplicación*).
Después funciona sin internet.
